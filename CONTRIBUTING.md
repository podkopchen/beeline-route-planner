# Разработка

Установка и запуск описаны в [README](README.md). Перед изменениями прочитайте [ограничения](docs/assumptions_and_limits.md) и [аудит](docs/qa-audit-2026-09-29.md).

- Имена новых файлов и каталогов — ASCII, Python — snake_case, React-компоненты — PascalCase. Русскоязычные тексты интерфейса сохраняются.
- Не изменяйте исходные CSV/XLSX/PDF и не используйте контрольное распределение. Имена внешних файлов организатора — часть контракта, а не naming проекта.
- Не коммитьте `.env`, ключи, логи, virtualenv, node_modules и результаты сборки.
- Изменения алгоритмов, нормативов и метрик требуют отдельных тестов; не подменяйте реальные результаты демонстрационными числами.
- Перед pull request выполните `powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/smoke.ps1`.
- Укажите изменение, тесты и известные ограничения. Успешные тесты не заменяют ручную проверку карты.
